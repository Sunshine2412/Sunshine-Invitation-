UNDANGAN PREMIUM V2

FITUR:
- Loading screen premium + opening invitation
- Personal guest name via URL: ?to=Nama%20Tamu
- Parallax hero
- Fullscreen gallery/lightbox
- Countdown
- RSVP + WhatsApp
- Penyimpanan RSVP lokal
- Opsi Google Sheets melalui google-apps-script.gs
- QR personal untuk link tamu
- Audio player: tambahkan assets/music.mp3
- Dashboard admin lokal: admin.html (PIN default 2026)
- Export RSVP CSV
- Responsive mobile

PENTING:
Edit CONFIG di index.html untuk nama, tanggal, rekening, nomor WhatsApp, dan endpoint Google Sheets.

Contoh link personal:
index.html?to=Bapak%20Andi

Untuk musik:
masukkan file MP3 dengan nama assets/music.mp3.

Untuk Google Sheets:
ikuti petunjuk di google-apps-script.gs lalu isi CONFIG.googleSheetsEndpoint.

Untuk deployment gratis:
folder ini bisa di-upload ke GitHub Pages, Netlify, Vercel, atau hosting biasa.
